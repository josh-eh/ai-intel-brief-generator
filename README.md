# AI Intel Brief Generator

## 🎯 Executive Overview & Purpose
This tool is designed to automate the initial drafting of executive briefs, improving efficiency and creating readability for both technical and non-technical users, while including a Human-in-the-Loop (HITL) step via Python script in order to ensure high quality reports. 

## 🛠️ Architecture & Features
- **Report Prompt:** A system prompt that instructs the AI to format the raw technical data into a crisp, "Smart Brevity" corporate intelligence brief.
- **Human-in-the-Loop Script:** A Python script to run after that requires a terminal prompt confirmation [y/n] in order to provide human oversight. 

## 🚀 Quick Start
```bash
git clone <repo-url>
pip install -r requirements.txt
python main.py
```
